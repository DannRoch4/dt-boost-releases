# DT BOOST · downloads

Otimizador de PC do canal [Dann Tech](https://www.youtube.com/@danntech): sensores, benchmark com prova antes/depois,
ajustes do Windows reversíveis, limpeza, upgrade e jogos. Em português.

**Baixe sempre por aqui:** [última versão](https://github.com/DannRoch4/dt-boost-releases/releases/latest) → `DTBoost-Setup-X.Y.Z.exe`.

- Instala só para o seu usuário, sem pedir administrador para instalar. O programa pede administrador ao abrir,
  porque mexe em configurações do Windows.
- Depois de instalado, o DT BOOST avisa sozinho quando sai versão nova e atualiza em um clique, conferindo o
  arquivo (SHA-256) antes de instalar.
- O Windows pode mostrar "O Windows protegeu o computador" por ser um programa novo: **Mais informações → Executar assim mesmo**.

Este repositório guarda só os instaladores. Requisitos: Windows 10 1809+ ou Windows 11, 64 bits.
